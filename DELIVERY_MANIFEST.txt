COMPONENT 2: calculate_approval_score() Tool
==============================================
Location: server.py, lines 188-271
Status: COMPLETE

Features:
- Aggregates weighted factors into 0-100 score
- Three normalization methods:
  1. Weighted Average: (Σ value × weight) / Σ(weights) - default, transparent
  2. Harmonic Mean: (Σ weights) / (Σ weight/value) - risk-averse
  3. Geometric Mean: Π(value ^ weight) - consensus-based
- Automatic weight normalization (handles arbitrary ranges)
- Category-level score aggregation
- Component analysis with contribution tracking
- Input validation (empty factors, weight bounds)

Input Schema:
  factors: Array of {name, value (0-100), weight (0-1), category, description, evidence}
  normalization: "weighted_average" | "harmonic" | "geometric"

Output Schema:
  overall_score: number (0-100)
  normalized_factors: Array
  category_scores: {financial, risk, operational, strategic}
  method: string
  factor_count: number

COMPONENT 4: assess_confidence_level() Tool
============================================
Location: server.py, lines 379-474
Status: COMPLETE

Features:
- Full Bayesian probability assessment
- Posterior probability calculation using Bayes' theorem
- Epistemic uncertainty quantification
- Certainty factor: (1 - variance) × data_quality
- Five-tier confidence classification

Bayesian Model:
- Prior probability: P(H) = 0.5 (configurable)
- Likelihood ratio: P(E|H) / P(E|¬H)
- Posterior odds: prior_odds × likelihood_ratio × evidence_strength
- Posterior probability: odds / (1 + odds)
- Certainty adjustment: posterior × (1 - variance) × data_quality
- Uncertainty penalty: uncertainty_factor × sqrt(variance)

Confidence Levels:
- very_high (0.85-1.0): Highly confident, recommend approval
- high (0.70-0.84): Confident with minor reservations
- medium (0.55-0.69): Moderate confidence, gather more data
- low (0.40-0.54): Low confidence, seek clarification
- very_low (0.0-0.39): Very uncertain, consider deferring

Input Schema:
  approval_score: number (0-100)
  factor_variance: number (0-1)
  data_quality: number (0-1)
  priors: {prior_probability, evidence_strength, uncertainty_factor}

Output Schema:
  confidence_level: string (5-tier)
  confidence_score: number (0-1)
  posterior_probability: number (0-1)
  certainty_factor: number (0-1)
  bayesian_analysis: {complete Bayesian details}
  factors: {input factors summary}

Test Coverage: 3 tests (confidence determination, Bayesian calculation, validation)
