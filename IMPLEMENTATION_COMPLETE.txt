✓ Debt-to-Income (DTI) Ratio Analysis

  - Provides recommendations for each level

✓ Credit Score Risk Assessment
  - Evaluates scores 300-850
  - Risk levels: EXCELLENT (800+), GOOD (750-799), FAIR (670-749),
                POOR (580-669), VERY_POOR (<580)
  - Estimates default probabilities: 1%-30%

✓ Loan Amount Analysis
  - Calculates loan-to-income ratio
  - Estimates monthly payment (60-month, 5% APR)
  - Risk assessment: LOW (≤2.0x), MEDIUM (2.0-2.5x), HIGH (2.5-3.0x), CRITICAL (>3.0x)

✓ Anomaly Detection (5 types)

  - VERY_LOW_CREDIT_SCORE: <500 (CRITICAL)

✓ Risk Aggregation

OPTION 1: Testing Environment (No MCP Server Required)
```python
import asyncio
from financial_risk_agent import FinancialRiskAgent, MockMCPToolInterface

async def main():
    agent = FinancialRiskAgent(mcp_interface=MockMCPToolInterface())
    
    assessment = await agent.assess_risk(
        applicant_id="APP001",
        credit_score=750,
        monthly_gross_income=6000,
        monthly_debt_payments=1200,
        loan_amount=250000,
    )
    
    print(f"DTI: {assessment.debt_to_income_ratio:.2%}")
    print(f"Risk: {assessment.overall_risk_level.value}")
    print(f"Recommendation: {assessment.approval_recommendation.value}")

asyncio.run(main())
```

OPTION 2: Production Environment (Requires MCP Server)
```python
from anthropic import Anthropic
from financial_risk_agent import FinancialRiskAgent, RealMCPToolInterface

client = Anthropic()
mcp_interface = RealMCPToolInterface(mcp_client=client)
agent = FinancialRiskAgent(mcp_interface=mcp_interface)

assessment = await agent.assess_risk(...)
```

================================================================================
RISK ASSESSMENT RETURN VALUE
================================================================================

Each assessment includes:

1. Applicant Information
   - applicant_id: str

2. Debt-to-Income Analysis
   - debt_to_income_ratio: float (e.g., 0.20 = 20%)
   - dti_risk_level: RiskLevel (low/medium/high/critical)
   - dti_recommendation: str (explanation)

3. Credit Score Analysis
   - credit_score: int (300-850)
   - credit_risk_level: str (excellent/good/fair/poor/very_poor)
   - credit_risk_percentage: float (default rate %)
   - credit_recommendation: str

4. Loan Analysis
   - loan_amount: float (requested amount)
   - loan_risk_level: RiskLevel
   - loan_recommendation: str

5. Anomalies
   - anomalies: List[Dict] (detected risk flags)
   - Each includes: flag_type, severity, message, threshold, actual_value

6. Overall Assessment
   - overall_risk_level: RiskLevel (aggregated from all factors)
   - approval_recommendation: ApprovalRecommendation (APPROVE/CONDITIONAL/DENY)

7. Reasoning
   - reasoning: str (detailed explanation of all factors)
   - detailed_analysis: Dict (complete MCP response)

BUSINESS RULES REFERENCE
================================================================================

DTI Risk Classification:
  ≤ 20%       → LOW (Excellent)
  20-36%      → LOW (Good)
  36-43%      → MEDIUM (Acceptable)
  43-50%      → HIGH
  > 50%       → CRITICAL

Credit Score Risk:
  800+        → EXCELLENT (1% default)
  750-799     → GOOD (2% default)
  670-749     → FAIR (5% default)
  580-669     → POOR (15% default)
  < 580       → VERY_POOR (30% default)

Loan-to-Income Risk:
  ≤ 2.0x      → LOW
  2.0-2.5x    → MEDIUM
  2.5-3.0x    → HIGH
  > 3.0x      → CRITICAL

Approval Decision:
  Score < 1.5   → APPROVE
  1.5-2.5       → CONDITIONAL
  ≥ 2.5         → DENY
