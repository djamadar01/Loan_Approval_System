## Core Concepts Quick Reference

### The Decision Classifications

```
APPROVE                    REVIEW                     REJECT
├─ Risk: 0-49             ├─ Risk: 50-84            ├─ Risk: ≥85
├─ No critical issues     ├─ Critical issues +      ├─ Unmitigable issues
├─ Confidence: 90-95%     │  mitigation possible    ├─ Confidence: 90-95%
└─ Example: Good loan     ├─ Escalation needed
                          ├─ Confidence: 70-85%
                          └─ Example: New vendor
```

### Risk Factor Weights

```
Overall Risk Score = (Financial × 0.35) + (Operational × 0.25) + 
                     (Compliance × 0.25) + (Reputational × 0.15)
```

### Decision Logic Flow

```
Input Risk Scores
        ↓
Calculate Weighted Risk Score
        ↓
Apply Classification Rules
        ↓
Extract Decision Factors
        ↓
Generate Explanation
        ↓
Return SynthesisResult
```

## Tool Reference

### Tool 1: synthesize_decision()

**Purpose:** Synthesize decisions from risk factors

**Key Parameters:**
- `financial_risk` (0-100): Credit, payment capacity
- `operational_risk` (0-100): Business stability
- `compliance_risk` (0-100): Regulatory adherence
- `reputational_risk` (0-100): Public perception
- `has_critical_issues` (bool): Critical problems exist
- `has_mitigating_factors` (bool): Risk mitigation present
- `requires_escalation` (bool): Human review needed

**Returns:** SynthesisResult with classification, risk score, confidence, factors, explanation

**Example:**
```python
from decision_synthesis_mcp import synthesize_decision

result = synthesize_decision(
    financial_risk=45,
    operational_risk=50,
    compliance_risk=55,
    reputational_risk=40,
)

print(f"Decision: {result.classification}")
print(f"Risk Score: {result.risk_score}")
print(f"Confidence: {result.confidence_level:.0%}")
```

### Tool 2: get_decision_rules()

**Purpose:** Retrieve complete decision rule set

**Returns:** Dictionary with risk calculation, classification rules, thresholds

**Example:**
```python
from decision_synthesis_mcp import get_decision_rules

rules = get_decision_rules()
print(rules['risk_score_calculation']['weights'])
print(rules['classification_rules']['APPROVE'])
```

## Decision Output Structure

### SynthesisResult Model

```json
{
  "classification": "Review",
  "risk_score": 62,
  "confidence_level": 0.8,
  "key_decision_factors": [
    "Risk score 62 in medium-high range (50-84)",
    "Critical issues require review"
  ],
  "explanation": "Decision: Review\nOverall Risk Score: 62/100\n..."
}
```

### Fields Explained

| Field | Type | Range | Meaning |
|-------|------|-------|---------|
| classification | String | Approve/Reject/Review | Decision category |
| risk_score | Integer | 0-100 | Overall risk level |
| confidence_level | Float | 0.0-1.0 | Decision certainty |
| key_decision_factors | List | Variable | Influencing factors |
| explanation | String | Variable | Detailed rationale |

## Troubleshooting

### Issue: ModuleNotFoundError: No module named 'fastmcp'
**Solution:** Install requirements
```bash
pip install fastmcp pydantic
```

### Issue: Risk scores out of range
**Solution:** Ensure values are 0-100
```python
# Invalid
synthesize_decision(financial_risk=150)

# Valid
synthesize_decision(financial_risk=50)
```

### Issue: Server won't start
**Solution:** Check Python version and dependencies
```bash
python --version  # Should be 3.8+
pip list | grep fastmcp  # Verify installed
```
