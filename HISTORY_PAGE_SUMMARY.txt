DATABASE INTEGRATION
================================================================================

Current: Sample data (5 applications)

To connect to database:
1. Modify load_sample_data() function
2. Import database module: from db import get_db
3. Query applications: db.list_applications()
4. Transform ApplicationRecord to expected format

Expected data format:
{
    "id": str,
    "applicant_name": str,
    "applicant_id": str,
    "email": str,
    "loan_amount": float,
    "loan_purpose": str,
    "status": str,
    "risk_level": str,
    "risk_score": float,
    "credit_score": int,
    "dti_ratio": float,
    "submission_date": str,
    "decision_date": Optional[str],
    "confidence": float,
    "factors": Dict[str, float],
    "explanation": str,
    "conditions": List[str],
    "recommended_interest_rate": Optional[float],
    "processing_time_days": Optional[int],
    "next_steps": List[str],
    "reviewer_notes": Optional[str]
}

Solution: Clear browser cache, check filter values match data
