================================================================================
                         CORE FEATURES
================================================================================

FOUR TOOLS PROVIDED:

1. get_applicant_profile(applicant_id: str) -> dict
   - Retrieves complete applicant profile
   - Returns Income Stability Score (0-100)
   - Includes Employment Risk level (low/medium/high)
   - Provides Credit History Summary
   - Shows Application Completeness Flags
   - Error handling for invalid IDs

2. list_all_applicants() -> dict
   - Lists all applicants in database
   - Returns total count and applicant summaries
   - Includes ID, name, email, status, application date

3. get_applicants_by_risk_level(risk_level: str) -> dict
   - Filters applicants by employment risk
   - Supports: "low", "medium", "high"
   - Returns filtered list with scores
   - Validates input parameters

4. get_applications_requiring_action() -> dict
   - Identifies incomplete applications
   - Shows missing documents
   - Lists required actions
   - Tracks completion percentage

PYDANTIC MODELS (Type-Safe):

1. IncomeStabilityScore
   - score: 0-100 integer
   - trend: String (increasing, stable, decreasing)
   - volatility: String (low, moderate, high)
   - average_monthly: Dollar amount

2. EmploymentRisk (Enum)
   - LOW = "low"
   - MEDIUM = "medium"
   - HIGH = "high"

3. CreditHistorySummary
   - credit_score: 300-850 range
   - accounts_on_time: Integer count
   - accounts_late: Integer count
   - total_debt: Dollar amount
   - debt_to_income_ratio: Percentage
   - delinquencies: Count

4. ApplicationCompletenessFlags
   - income_documentation_required: Boolean
   - employment_verification_required: Boolean
   - identity_verification_required: Boolean
   - credit_authorization_required: Boolean
   - missing_fields: List of strings
   - completion_percentage: 0-100

5. ApplicantProfile
   - Complete profile combining all data
   - applicant_id, name, email, phone
   - income_stability, employment_risk
   - credit_history, completeness
   - application_date, status
