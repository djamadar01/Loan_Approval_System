================================================================================
REQUEST/RESPONSE SUMMARY
================================================================================

Request Model: LoanApplicationRequest
  - applicant_id: string (1-255 chars)
  - profile: object (required fields)
  - credit_score: integer (300-850)
  - loan_amount: float (> 0)
  - tenure: integer (1-480)
  - liabilities: float (≥ 0)
  - location: string (1+ chars)
  - timestamp: string (ISO 8601)

Response Model: LoanDecisionResponse
  - case_id: string (CASE-YYYYMMDD-XXXXXXXX)
  - classification: string (approved|rejected|manual_review|conditional_approval)
  - risk_score: float (0-100)
  - confidence: float (0-1)
  - factors: array (DecisionFactor objects)
  - explanation: string (decision rationale)
  - conditions: array (approval conditions)
  - required_documents: array (required docs)
  - processed_at: string (ISO 8601)
  - processing_time_ms: float

Error Response: ErrorResponse
  - error_code: string (error identifier)
  - error_message: string (description)
  - details: object (additional info)
  - case_id: optional string (tracking)
  - timestamp: string (ISO 8601)

================================================================================
API ENDPOINTS
================================================================================

GET /health
  Purpose: Health check
  Response: Status, version, orchestrator ready flag
  Status Code: 200

POST /submit-application
  Purpose: Process loan application
  Request: LoanApplicationRequest
  Response: LoanDecisionResponse
  Status Codes: 200 (success), 422 (validation), 500 (error), 503 (unavailable)

POST /test-application (Development)
  Purpose: Test with sample data
  Response: Sample LoanDecisionResponse
  Status Code: 200

================================================================================
ERROR HANDLING
================================================================================

Validation Error (422):
  - Invalid input format
  - Out-of-range values
  - Missing required fields
  - Invalid field values
  - Returns detailed validation errors

Server Error (500):
  - Unexpected processing failures
  - Returns case ID for tracking
  - Logged for debugging

Service Unavailable (503):
  - Orchestrator not initialized
  - Service temporarily down
  - Suggest retry later

    },
    "credit_score": 720,
    "loan_amount": 25000,
    "tenure": 60,
    "liabilities": 10000,
    "location": "New York, NY"
  }

Invalid Applications (Will Be Rejected):
  - credit_score: 200 (below 300)
  - age: 17 (below 18)
  - tenure: 500 (above 480)
  - loan_amount: -5000 (negative)
  - annual_income: 0 (must be positive)

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Issue: API won't start
  → Check Python version (3.8+)
  → Install dependencies: pip install -r requirements.txt
  → Check port 8000 is available

Issue: Import errors
  → Ensure you're in the correct directory
  → Add directory to Python path
  → Install missing dependencies

Issue: Orchestrator not initialized
  → Ensure loan_orchestrator.py is accessible
  → Check LangGraph dependencies installed
  → Verify Anthropic SDK configured

Issue: Validation errors
  → Review error message in response
  → Check field constraints
  → Validate data types and ranges

Issue: Slow processing
  → Check LLM API availability
  → Monitor network connectivity
  → Increase timeout if needed

More Help:
  → See LOAN_API_GUIDE.md for detailed documentation
  → Check example_client_usage.py for patterns
  → Review test_loan_api.py for test examples
