CONFIGURATION OPTIONS
================================================================================

Customizable via MonitoringConfig class:

LOG_DIR                    Directory for log files (./logs)
LOG_FILE                   Text log filename
JSON_LOG_FILE              JSON log filename
ERROR_LOG_FILE             Error log filename
LOG_LEVEL                  Logging level (logging.INFO)
LOG_FORMAT                 Log message format

METRICS_PORT               Metrics port (8001)
METRICS_ENDPOINT           Metrics path (/metrics)

HEALTH_CHECK_ENDPOINT      Health endpoint (/health)

MAX_ERRORS_STORED          Max errors in memory (1000)
ERROR_ALERT_THRESHOLD      Alert trigger count (10)
ERROR_WINDOW_SECONDS       Alert time window (300)

SLOW_REQUEST_THRESHOLD     Request slowness limit (1.0s)
SLOW_DECISION_THRESHOLD    Decision slowness limit (0.5s)

================================================================================
USAGE EXAMPLES
================================================================================

BASIC SETUP:
from flask import Flask
from monitoring import setup_monitoring

app = Flask(__name__)
logger, metrics, error_tracker, health_checker = setup_monitoring(app)

STRUCTURED LOGGING:
logger.info("User created", user_id=user.id, email=user.email)
logger.error("Database error", operation="insert", retry_count=3)

DECISION TIMING:
@track_decision("recommendation_engine")
def get_recommendation():
    return recommendation

ERROR TRACKING:
@track_errors
def risky_operation():
    perform_operation()

CUSTOM TIMING:
with DecisionTimer(metrics, "operation_name", logger):
    perform_operation()
