## Decision System Implementation

### Risk Scoring Algorithm
```
Profile Risk (0-100):
  - Credit Score: 0-40pts
  - Employment: 0-30pts
  - Duration: 0-20pts
  - Education: ±10pts
  - Existing Loans: 0-20pts
  - Age Factor: 0-15pts

Financial Risk (0-100):
  - DTI Ratio: 0-40pts
  - Savings: 0-20pts
  - Income Adequacy: 0-35pts

Final Decision Score: 100 - (Profile×0.3) - (Financial×0.4) - RiskPenalty
```

### Decision Types
| Score | Decision | Action |
|-------|----------|--------|
| ≥75 | APPROVED | Approval letter, Disbursement |
| 60-74 | CONDITIONAL_APPROVAL | Request documents |
| 40-59 | MANUAL_REVIEW | Underwriter routing |
| <40 | REJECTED | Rejection letter |
