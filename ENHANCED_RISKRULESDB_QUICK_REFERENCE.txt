FEATURE 1: CONFIGURABLE RISK THRESHOLDS API (3 tools)
================================================================================

configure_risk_threshold()
  ├─ Update existing metric thresholds
  ├─ Parameters: metric, low, moderate, high, critical
  └─ Use: Adapt to policy/regulatory changes

add_custom_risk_threshold()
  ├─ Create new metric thresholds
  ├─ Parameters: metric, name, thresholds, unit, description
  └─ Use: Track new risk factors

get_all_risk_thresholds()
  ├─ View all configured thresholds
  ├─ Returns: All metrics with current values
  └─ Use: Audit and review configuration

================================================================================
FEATURE 2: HISTORICAL RISK TRENDING (4 tools)
================================================================================

record_risk_assessment()
  ├─ Store assessment in time-series database
  ├─ Parameters: entity_id, risk_score, risk_level, metrics...
  └─ Use: Create audit trail and trend history

get_risk_history()
  ├─ Retrieve historical assessments
  ├─ Parameters: entity_id, limit
  └─ Use: View past decisions

calculate_risk_trend()
  ├─ Analyze trend direction over time
  ├─ Parameters: entity_id, period_days
  └─ Returns: Direction (improving/stable/deteriorating), statistics

get_cohort_statistics()
  ├─ Compare groups by risk level
  ├─ Parameters: risk_level, period_days
  └─ Returns: Mean, median, min, max, stdev

================================================================================
FEATURE 3: ANOMALY DETECTION WITH ML (1 tool + 4 methods)
================================================================================

detect_financial_anomalies()
  ├─ Run ML ensemble detection
  ├─ Methods: Z-score, Isolation Forest, Spending Pattern, Velocity
  ├─ Parameters: entity_id, dti_ratio, credit_score, loan_amount, income, spending_pattern
  └─ Returns: Anomalies, risk_score, recommendations, confidence

Anomaly Types:
  ├─ SPENDING_SPIKE          (unusual spending increase)
  ├─ UNUSUAL_PATTERN         (deviation from behavior)
  ├─ HIGH_VELOCITY           (rapid transactions)
  ├─ ACCOUNT_AGE             (new account behavior)
  ├─ GEOGRAPHIC_ANOMALY      (unusual location)
  └─ INCOME_VARIANCE         (income changes)

================================================================================
FEATURE 4: REGULATORY RULE VERSIONING (3 tools)
================================================================================

get_active_regulatory_rules()
  ├─ View all active compliance rules
  ├─ Default: ECOA, FCRA, GLBA
  └─ Returns: Rules organized by type with versions

create_regulatory_rule_version()
  ├─ Create new rule version
  ├─ Parameters: rule_id, name, type, version, content
  └─ Use: Update compliance rules with audit trail

validate_compliance()
  ├─ Check entity against regulatory rules
  ├─ Parameters: entity_data, rule_types
  └─ Returns: compliant (true/false), violations list

================================================================================
FEATURE 5: CUSTOM RULE ENGINE (4 tools)
================================================================================

create_custom_threshold_rule()
  ├─ Create simple threshold rule
  ├─ Parameters: rule_id, name, metric, threshold, operator
  └─ Example: "dti_ratio < 0.43"

create_custom_complex_rule()
  ├─ Create multi-condition rule
  ├─ Parameters: rule_id, name, conditions[], logic (AND/OR)
  └─ Example: "(dti > 0.50) AND (credit < 600)"

evaluate_custom_rules()
  ├─ Run custom rules against data
  ├─ Parameters: data, rule_ids (optional)
  └─ Returns: Pass/fail results, compliance_score

get_custom_rules()
  ├─ List all registered custom rules
  └─ Returns: All rules with priority and status

================================================================================
COMMON WORKFLOWS
================================================================================

WORKFLOW 1: Initial Risk Assessment
  1. configure_risk_threshold() - Set policy
  2. comprehensive_risk_analysis() - Analyze applicant
  3. Result: Approve/Deny/Conditional

WORKFLOW 2: Portfolio Monitoring
  1. record_risk_assessment() - Log after each decision
  2. get_cohort_statistics() - Daily portfolio analysis
  3. calculate_risk_trend() - Monitor high-risk segment
  4. Result: Early warnings, interventions

WORKFLOW 3: New Policy Rollout
  1. create_custom_complex_rule() - Define new rules
  2. evaluate_custom_rules() - A/B test on subset
  3. create_regulatory_rule_version() - Version control
  4. calculate_risk_trend() - Measure impact
  5. Result: Data-driven rollout

WORKFLOW 4: Fraud Investigation
  1. detect_financial_anomalies() - Flag suspicious
  2. get_risk_history() - Historical patterns
  3. validate_compliance() - Rule violations
  4. Result: Investigation context

WORKFLOW 5: Regulatory Audit
  1. get_active_regulatory_rules() - Current rules
  2. validate_compliance() - Sample validation
  3. create_regulatory_rule_version() - Document changes
  4. get_risk_history() - Audit trail
  5. Result: Compliance documentation

================================================================================
KEY PARAMETERS & VALUES
================================================================================

Risk Levels:
  - "low"       (score 0.0-0.25)
  - "moderate"  (score 0.25-0.50)
  - "high"      (score 0.50-0.75)
  - "critical"  (score 0.75-1.0)

Operators (for custom rules):
  - ">"  (greater than)
  - "<"  (less than)
  - ">=" (greater or equal)
  - "<=" (less or equal)
  - "==" (equals)

Logic (for complex rules):
  - "AND" (all conditions must be true)
  - "OR"  (any condition can be true)

Default Thresholds:
  - DTI:        0.36 (moderate), 0.50 (high), 0.75 (critical)
  - Credit:     670 (moderate), 580 (high), 300 (critical)
  - LTI:        2.5 (moderate), 3.5 (high), 4.5 (critical)
  - Income:     $50k (moderate), $30k (high), $15k (critical)

ML Confidence Range:
  - Min: 0.50 (low confidence)
  - Max: 0.95 (high confidence)

================================================================================
TROUBLESHOOTING
================================================================================

No history found?
  └─ Check entity_id matches, ensure record_risk_assessment called first

Threshold not updating?
  └─ Verify metric name, use get_all_risk_thresholds to see valid names

Anomaly score unexpected?
  └─ Check input data ranges, verify spending_pattern format

Compliance violation?
  └─ Review rule content, validate entity_data structure

Custom rule not triggering?
  └─ Check rule_id is registered, verify operator syntax
