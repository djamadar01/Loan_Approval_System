================================================================================
COMMON TASKS
================================================================================

ANALYZE AN INVESTMENT DECISION:
  1. Define 3-5 factors with scores, weights, and categories
  2. Call calculate_approval_score() to get aggregate score
  3. Call generate_decision_rationale() to explain factors
  4. Call assess_confidence_level() to quantify uncertainty
  5. Call format_decision_output() for final report

ASSESS DECISION CONFIDENCE:
  1. Get approval_score from calculate_approval_score()
  2. Calculate factor_variance from factor scores
  3. Estimate data_quality (0.7-0.95 typical)
  4. Call assess_confidence_level() with parameters
  5. Review confidence_level and posterior_probability

UNDERSTAND FACTOR IMPACT:
  1. Review generate_decision_rationale() output
  2. Check impact classification (5 levels)
  3. Examine factor_explanations for each component
  4. View category_summary for high-level insights
  5. Use evidence field for supporting documentation

GENERATE DECISION REPORT:
  1. Prepare all analysis components (scores, rationale, confidence)
  2. Call format_decision_output() with complete parameters
  3. Receive structured JSON with:
     - Decision outcome (approved/rejected/conditional/deferred)
     - Approval and confidence scores
     - Factor-by-factor analysis
     - Auto-generated recommendations
     - Required conditions (if any)
  4. Export JSON for stakeholder distribution

================================================================================
ERROR SCENARIOS & RESOLUTION
================================================================================

ERROR: "At least one factor required"
CAUSE: Empty factors array provided
SOLUTION: Provide at least one factor

ERROR: "Total weight cannot be zero"
CAUSE: All factors have zero weight
SOLUTION: Assign positive weights to factors

ERROR: "Approval score must be 0-100"
CAUSE: Score outside valid range
SOLUTION: Provide score between 0 and 100

ERROR: "Unknown normalization method"
CAUSE: Invalid normalization parameter
SOLUTION: Use "weighted_average", "harmonic", or "geometric"

ERROR: "Invalid factor format"
CAUSE: Missing required factor fields
SOLUTION: Ensure name, value, weight present and valid

ERROR: "Factor variance must be 0-1"
CAUSE: Variance parameter out of range
SOLUTION: Provide variance between 0 and 1
