================================================================================
WORKFLOW ARCHITECTURE
================================================================================

Processing Pipeline (8 Stages):
  1. Input Validation
     ├─ Verify required fields
     └─ Initialize execution log

  2. Profile Analysis (ApplicantProfileAgent)
     ├─ Credit score analysis
     ├─ Employment evaluation
     ├─ Education assessment
     └─ Profile risk score (0-100)

  3. Financial Risk Assessment (FinancialRiskAgent)
     ├─ DTI ratio calculation
     ├─ Savings analysis
     ├─ Income adequacy
     └─ Financial risk score (0-100)

  4. Risk Aggregation
     ├─ Combine all risk factors
     ├─ Identify risk factors
     ├─ Identify mitigating factors
     └─ Overall risk level (LOW/MEDIUM/HIGH/CRITICAL)

  5. Loan Decision (LoanDecisionAgent)
     ├─ Calculate decision score
     ├─ Determine decision type
     ├─ Set approval probability
     └─ Specify conditions/requirements

  6. Compliance Check (ComplianceOrchestratorAgent)
     ├─ AML/KYC verification
     ├─ Age verification
     ├─ Fraud detection
     ├─ Enhanced due diligence
     └─ Required actions

  7. Output Formatting
     ├─ Aggregate results
     ├─ Set final status
     └─ Update timestamps

  8. END
     └─ Return complete ApplicationState

Error Handling:
  - At any stage, if error occurs
  - Route to error handler (non-fatal)
  - Continue to output formatting
  - Preserve audit trail
  - Status set to ERROR

STATE MANAGEMENT
================================================================================

ApplicationState Components:
  ✓ application_id: Unique identifier
  ✓ status: Current application status
  ✓ applicant_profile: Profile data with risk score
  ✓ financial_data: Financial metrics with calculations
  ✓ risk_assessment: Comprehensive risk analysis
  ✓ loan_decision: Decision and rationale
  ✓ compliance_result: Compliance status and actions
  ✓ errors: Error tracking list
  ✓ execution_log: Complete audit trail
  ✓ created_at, updated_at: Timestamps

State Transitions:
  PENDING → PROFILE_ANALYZED → RISK_ASSESSED → DECISION_MADE 
  → COMPLIANCE_CHECKED → APPROVED/REJECTED/FLAGGED

Error State:
  Any Stage → ERROR (non-fatal, continues to output)

================================================================================
DECISION ENGINE
================================================================================

Scoring Formula:
  Decision Score = 100 
                 - (Profile Risk × 0.3) 
                 - (Financial Risk × 0.4)
                 - (Risk Level Penalty)

Decision Thresholds:
  ✓ Score ≥ 75: APPROVED (95% probability)
  ✓ 60-74: CONDITIONAL_APPROVAL (70% probability)
  ✓ 40-59: MANUAL_REVIEW (40% probability)
  ✓ <40: REJECTED (5% probability)

Risk Scoring:
  Profile Risk (0-100):
    - Credit Score: 0-40pts
    - Employment Status: 0-30pts
    - Employment Duration: 0-20pts
    - Education Level: ±10pts
    - Existing Loans: 0-20pts
    - Age Factor: 0-15pts

  Financial Risk (0-100):
    - DTI Ratio: 0-40pts
    - Savings Adequacy: 0-20pts
    - Income Adequacy: 0-35pts

Risk Levels:
  ✓ LOW: Average < 40
  ✓ MEDIUM: 40-59
  ✓ HIGH: 60-74
  ✓ CRITICAL: ≥75

    - Request additional documentation

  REJECTED:
