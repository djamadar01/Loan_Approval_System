  Endpoint: POST /loan/apply

  current_page: Current navigation page

  last_decision: Most recent decision result

DEPLOYMENT OPTIONS
================================================================================

LOCAL DEVELOPMENT:
  1. Install: pip install -r requirements_streamlit.txt
  2. Backend: python server.py (in one terminal)
  3. Frontend: streamlit run app.py (in another terminal)
  4. Access: http://localhost:8501

DOCKER:
  Single Service:
    docker build -f Dockerfile.streamlit -t loan-app-streamlit .
    docker run -p 8501:8501 loan-app-streamlit

  Full Stack:
    docker-compose -f docker-compose.complete.yml up
